# 🛠️ Error Handler: Глобальный обработчик ошибок

### 📌 Описание 

Рабочий процесс реализует отказоустойчивую систему для n8n-сервера. Вместо дублирования блоков уведомлений и усложнения логики внутри каждого отдельного сценария, создана единая точка перехвата сбоев («Error Router»), которая в автоматическом режиме собирает системные метаданные и отправляет сигналы.

### 🛠 Какая была проблема?

При масштабировании low-code автоматизации на продакшене отсутствовала система мониторинга ошибок

### 💡 Реализованное решение 

Процесс перехвата сбоев и информирования полностью изолирован в централизованный сервисный воркфлоу:

1. **Глобальный перехват:** Нативный узел **Error Trigger** выступает в роли системного роутера, мгновенно перехватывая любые  исключения из всех активированных воркфлоу.
2. **Парсинг метаданных:** Кастомные выражения n8n динамически вытаскивают из контекста ошибки ключевую системную информацию: точное название упавшего процесса (`$json.workflow.name`) и конкретный узел, на котором произошел сбой (`$json.execution.lastNodeExecuted`).
3. **Генерация глубоких ссылок:** Сценарий автоматически формирует валидный динамический URL, ведущий на страницу детального лога упавшей ноды
4. **Изолированные сигналы:** Узел SMTP осуществляет отправку структурированного HTML-письма с техническими деталями на email.

### 🎯 Результат

- **Чистота рабочих пространств:** Основные бизнес-воркфлоу остаются легковесными, так как вся логика обработки ошибок вынесена в один внешний компонент.
- **Мгновенная диагностика:** Возможность моментально узнать контекст сбоя и перейти к проблемному участку по прямой ссылке, минуя ручной поиск в истории выполнений.
- **Оптимизация под Production:** Решение разгружает сервер n8n и оптимизирует работу основных бизнес-воркфлоу.
